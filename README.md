# Chapter 1 Research Writing Quest

A free, static, mobile-friendly teaching game for Level 5 students.

## What students do
In **Guided Example** mode, students work through five Chapter 1 components:
1. Business Context and Background
2. Research Problem and Importance
3. Research Aim
4. Research Objectives
5. Research Questions

Each challenge: guidance → first draft → model answer → self-mark → revision → Great Learner badge.

In **My Research Project** mode, students enter their own research details and write all five components with guidance and self-checks **without model answers**.

The example is based on the entrepreneurship study in the instructor's Chapter 4 teaching materials. Model writing is illustrative; any real-world assertions require sources.

## Publish on GitHub Pages
1. Create a **public** repository named `chapter1-research-writing-quest` in your GitHub account.
2. Upload `index.html`, `style.css`, `app.js` and `README.md` to the repository **root**.
3. Go to **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. Once GitHub finishes deployment, the URL will usually be:
   `https://YOUR-USERNAME.github.io/chapter1-research-writing-quest/`
5. Test the full game on desktop and mobile before distributing a QR code.

## Notes
- No backend or external libraries required.
- Drafts and progress are saved in each student's own browser (`localStorage`). They are **not** transmitted to the instructor.
- Students should download their drafts before clearing browser data or changing devices.
- Badges recognise participation and revision, **not verified academic achievement**.
- Instructors should assess the final drafts and check research claims, evidence and alignment.
